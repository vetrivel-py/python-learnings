# Guess the Number Game

A simple command-line Python game where the player attempts to guess a randomly chosen number between 1 and 100.

## Features

- Prompts the player to guess a number between 1 and 100
- Provides feedback if the guess is too high or too low
- Continues until the correct number is guessed

## Getting Started

### Prerequisites

- Python 3.x installed on your system

### Running the game

1. Clone the repository:
   ```bash
   git clone https://github.com/vetrivel-py/python-learnings.git
   cd python-learnings/Guess_number
   ```
2. Run the script:
   ```bash
   python3 main.py
   ```
3. Follow the prompts in the terminal to play.
